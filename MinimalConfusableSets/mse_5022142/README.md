# Files attached to math.stackexchange question 5022142

These are the three files attached to the question
[*Constraints under which collections of position vectors are never confusable with others, given only access to scalar products in certain directions*](https://math.stackexchange.com/questions/5022142),
posted on 2025-01-11. They are kept here so that the question's figure and data survive even if the
external links break.

- `37_confusable.png`: the figure in the question (`i.sstatic.net/1DKhRU3L.png`).
- `37_confusable.svg`: the same figure as SVG, linked from a comment
  (`hep.phy.cam.ac.uk/~lester/37_confusable.svg`).
- `37_points_data.txt`: the 37 red and 37 blue points, the 7 directions, and every sorted scalar
  product, linked under the figure (`hep.phy.cam.ac.uk/~lester/37_points_data.txt`).

The red and blue sets have the same sorted scalar products in all 7 directions, so 7 bats in the plane
are fooled by 37 moths. The figure was drawn by `examples/plot.py` (which writes
`example.svg`). In the figure, the origin is at the top left and y increases downwards.

Each file is byte-identical to the copy that was online on 2026-10-22.
